# Architecture & Design Rationale: Vigil (NSE / BSE Edition)

This document details the architectural decisions, trade-offs, and engineering principles behind **Vigil**, structured directly against the **CODE 2026 Evaluation Dimensions**.

---

## 1. Product & Problem Interpretation (Understanding Beyond the Brief)

### The Core Problem: The "Noise vs. Attention" Dilemma
Standard watchlists are static ticker boards. They display quotes anchored to yesterday?s 15:30 IST market close. When a trader or investor steps away from their desk for an hour and returns, knowing that "Reliance is +0.8% today" is nearly useless:
- Did it rally in the morning and go flat, or did it just experience a sharp drop in the last 20 minutes?
- Did it move simply because the broader Nifty index jumped, or is it decoupling on company-specific news?
- Did heavy institutional volume accompany the move?

### The Solution: "Stateful Absence Awareness"
Vigil introduces the concept of a **Session Checkpoint Ledger**:
1. When you open your terminal, your viewing timestamp ($T_0$) and baseline price snapshot are registered in the database.
2. When you return at $T_1$, Vigil computes **Differential Deltas** $(\Delta P, \Delta \%, \Delta \text{Volume})$ specifically across your absence window.
3. Once you review what happened, you click **"Mark as Reviewed"**, which advances your checkpoint to the present moment, resetting deltas to ?0.00 until new drift occurs.

### Deterministic Attribution Rules
Rather than using opaque LLM hallucinations that generate vague text, Vigil defines **3 deterministic rules** for "Meaningful Change":
1. **Significant Price Swing**: Price moved $\ge \pm 2.0\%$ since your checkpoint.
2. **Nifty Decoupling (Alpha Divergence)**:
   $$\text{Expected Return} = \beta_i \times \Delta r_{\text{NIFTY}}$$
   $$\text{Alpha Divergence} = \Delta r_i - \text{Expected Return}$$
   If $|\text{Alpha Divergence}| \ge 1.5\%$, it indicates an idiosyncratic, company-specific shock rather than routine market tide.
3. **Volume Surge**: Observed volume pacing is $\ge 1.5\times$ typical historical volume for this time of day.

## 3. Edge Cases & Resilience

| Edge Case | Root Cause | Engineering Solution |
| :--- | :--- | :--- |
| **Market Closed / Weekend Review** | Evaluators testing outside 09:15?15:30 IST see static quotes with 0 volume. | The system detects IST session status and displays explicit badges (`CLOSED ? IST`). Furthermore, the **Time-Machine Scrubber** allows judges to simulate stepping away 30m, 2h, or injecting live shocks at any time. |
| **Rapid Page Refreshes / Rate Limits** | High frequency polling drains server and upstream resources. | Server-side in-memory caching with a 15-second TTL ensures identical quotes are served in sub-millisecond time. |
| **User Alert Fatigue** | Users get overwhelmed by persistent alert states. | The **"Mark as Reviewed"** action button allows traders to acknowledge current state, resetting deltas to baseline and clearing the executive feed. |
| **Data Integrity on Server Restart** | Restarting servers loses session bookmarks. | Persistent SQLite database using Write-Ahead Logging (`PRAGMA journal_mode = WAL`) guarantees atomicity and zero data corruption. |

## 4. Code Quality & Simplicity (No Over-Engineering)

- **Single-Service Architecture**: Instead of running separate containers for backend, frontend, and database, Express serves the compiled React static files directly in production (`client/dist`). This means the entire application deploys online as **one unified web service** without CORS issues.
- **Embedded Storage**: SQLite operates within the Node process, requiring zero background daemons, zero Docker requirements for local development, and zero database connection pool configuration.
- **Clean TypeScript Contracts**: Types are shared conceptually across backend and frontend, ensuring complete type safety.

## 5. Originality & Thoughtfulness

1. **The Checkpoint Bookmark Line on Sparklines**: Every sparkline in the watchlist table features a distinct dashed vertical line indicating the exact minute you last checked, visually separating "historical trend" from "what happened while you were away."
2. **Indian Market Grounding**: All figures are formatted in natural Indian conventions: native `?` symbols, Lakhs (`L`) and Crores (`Cr`) volume notations, and NIFTY 50 / SENSEX benchmark divergence.
3. **Action-Oriented Attention Tiers**: Automatically filters the portfolio into ?? Urgent, ?? Developing, and ?? Steady, eliminating the need to scan 20 rows of identical numbers.
